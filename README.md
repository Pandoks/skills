# Pandoks Skills

## Install

List the available skills:

```sh
npx skills add Pandoks/skills --list
```

Install interactively:

```sh
npx skills add Pandoks/skills
```

## Skills

| Skill             | Purpose                                                             |
| ----------------- | ------------------------------------------------------------------- |
| `create-worktree` | Place and name Git worktrees consistently next to the project root. |
