# Worktree Creation Rules

- Always create worktrees on the same level as the project root.
- Naming convention: `<main-branch-directory-name>_<branch-name>`.

## Example

If the `main`/`master` branch is in `/Users/you/my-app` and the branch is `feature/login`, create:
`/Users/you/my-app_feature-login`.
